# Virgin Fund - Portfolio Management System

A comprehensive platform for creating and managing investment portfolios, tracking transactions, and analyzing performance.

## Features

- **Portfolio Management**: Create and manage multiple investment portfolios with different risk profiles
- **Asset Tracking**: Track multiple assets across portfolios with real-time price updates
- **Transaction Recording**: Record buy/sell transactions with detailed history
- **Performance Analysis**: Visualize portfolio performance over different timeframes
- **Benchmark Comparison**: Compare your portfolio against market benchmarks

## Technology Stack

- React 18
- TypeScript
- CSS3 with CSS Variables

## Getting Started

### Prerequisites

- Node.js (v16.0.0 or higher)
- npm (v8.0.0 or higher)

### Installation

1. Clone the repository
   ```
   git clone https://github.com/your-organization/virgin-fund.git
   cd virgin-fund
   ```

2. Install dependencies
   ```
   npm install
   ```

3. Start the development server
   ```
   npm start
   ```

4. Build for production
   ```
   npm run build
   ```

## Project Structure

- `/app`: Core application logic
  - `/models`: Data models and type definitions
  - `/services`: Business logic and API integration
  - `/styles`: CSS styles
- `/components`: React components organized by feature
- `/docs`: Documentation files
